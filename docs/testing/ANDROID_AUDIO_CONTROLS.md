# Receiver 音量与静音测试（Experimental）

这是 M2 的接收端本地声音控制，不是 Sender 遥控协议，也不改变系统全局音量。
请由设备持有人安装匹配版本的双 APK 并操作；无需交出设备或授予代理 ADB 权限。
可先发送 30 秒参考测试流：它每秒包含约 80 ms 的 880 Hz 短提示音，
可以检查音量与静音。内部 `NativePlaybackTest` 才使用静音 AAC 探针，两者不同。
也可按 [屏幕共享说明](ANDROID_SCREEN_CAPTURE.md) 建立有声音的投屏。

更正：`81b64c5` 预览压缩包的交付说明曾误写参考流为静音。包内代码实际
包含上述短提示音；旧压缩包不重写，请以本说明为准，始终先调低接收端音量。

## 操作

1. 使用允许音频捕获的无 DRM 测试音源，避免私人内容；Android 10+ Sender
   选择播放音频采集并授予系统要求的权限。不采集麦克风。
2. 先把 Receiver 系统音量调低，不戴耳机测试突发声音。在播放画面下方找到
   帧舟音量条、±10 按钮和“静音帧舟声音”。新安装或旧版本升级首次使用为
   50%、未静音；设备系统静音时这里不会替你打开系统声音。
3. 分别尝试 0%、25%、50% 和静音，确认画面继续、声音随之变化，系统全局
   音量未被界面改变。这里的百分比是线性增益，不是实测响度或分贝。
4. 保持静音并调高滑块或按 +10，应仍无声音；只有明确取消静音才恢复当前
   音量。观察恢复后是否播放旧声音、爆音、画面卡顿或音画失步。
5. 结束接收后重开服务；退出应用后重新打开，核对已完成调整的音量与静音
   是否保留。拖动滑块在松手后保存，未松手就中断的调整不保证持久化。
6. 有电视遥控器时，用方向键移动焦点；滑块左右键每次 ±5，±10 按钮和
   静音框用确认键操作。记录焦点是否可见、能否滚动到控制区。
7. 若显示“保存失败”，当前播放设置已生效但下次启动请重新核对；若显示
   “声音控制失败”，播放会停止并保持静音，请先确认设备音频能力再明确
   重启。清除应用数据会清除设置并恢复 50%、未静音，不能当作保留静音。

## 回传结果

请记录双 APK 版本、Sender/Receiver 型号和系统版本、使用手机/电视、音频
输出方式（扬声器/有线/蓝牙/HDMI）、测试音源是否允许捕获，以及以上每步
通过/失败/未测。没有声音时说明系统音量、投屏前音源是否有声和采集权限。
无需提供 PIN、完整设备身份、局域网地址、私钥、私人媒体或原始抓包。

模拟器仅证明本地控制、真实 AudioTrack 接口接受增益和解码继续；不证明
真机听感、静音延迟、路由切换、长时间稳定或 M2 完成。
